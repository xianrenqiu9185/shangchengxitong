# 鉴权接口契约（v1）

> 维护：A（后端负责人）
> 约定：所有接口返回统一 `Result<T>`；Token 采用方案 B（随机 Token 存 Redis）。

## 1. 登录

```http
POST /api/v1/auth/login
Content-Type: application/json
```

```json
{ "phone": "13800000003", "password": "123456" }
```

成功响应：

```json
{
  "code": 0,
  "message": "OK",
  "data": {
    "token": "…",
    "user": {
      "id": 3,
      "phone": "13800000003",
      "nickname": "邻里会员",
      "userType": 1,
      "roleId": 1,
      "role": "member"
    },
    "permissions": ["trade:order:create", "product:goods:view"]
  },
  "traceId": "…",
  "timestamp": 1792378874909
}
```

`role` 取值：`member` / `operator` / `admin`。

## 2. 当前用户

```http
GET /api/v1/users/me
Authorization: Bearer <token>
```

响应：

```json
{
  "code": 0,
  "message": "OK",
  "data": {
    "user": {
      "id": 3,
      "phone": "13800000003",
      "nickname": "邻里会员",
      "userType": 1,
      "roleId": 1,
      "role": "member"
    },
    "permissions": ["trade:order:create"]
  }

```

## 3. 注册

```http
POST /api/v1/auth/register
Content-Type: application/json
```

```json
{ "phone": "13900000000", "password": "abc12345", "nickname": "新会员" }
```

响应：`data` 为用户 ID（`long`）。

> **注册不签发 Token**：前端注册成功后跳转登录页，再调用登录接口。

## 4. 注销

```http
POST /api/v1/auth/logout
Authorization: Bearer <token>
```

删除 Redis 会话，幂等。

## 5. 会话约定

- Redis：`auth:session:{token} → userId:userType:roleId`，TTL 2 小时，滑动续期。
- 用户会话集合：`auth:user:{userId}:sessions`（Set），用于禁用/踢下线批量撤销。
- 登录失败：`auth:login:fail:{phone}`，连续 5 次锁定 15 分钟。
- 前端存储：Token 存 `localStorage`（设计文档 8.4）；请求头 `Authorization: Bearer <token>`。

## 6. 错误码

| 码 | 含义 |
| --- | --- |
| 10001 | 参数错误 |
| 10002 | 未登录或登录失效 |
| 10003 | 无操作权限 |
| 10005 | 账号已被禁用 |
| 10006 | 手机号已注册 |
| 10007 | 手机号或密码错误 |
| 10008 | 登录失败次数过多，请稍后再试 |
| 90001 | 系统异常 |
