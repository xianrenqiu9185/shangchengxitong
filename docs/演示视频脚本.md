# 邻里鲜生 · 演示视频脚本与录制指南（≤ 15 分钟）

> 用途：结项演示录屏。角色 D 负责录制与剪辑，A/B/C 出镜配合。
> 建议：1920×1080、30fps，正片 12 分钟，留 3 分钟余量。

## 7. 录制操作教程

### 7.1 OBS 设置（首次配置 5 分钟）

1. 打开 OBS → 右下「设置」→「输出」，码率 6000 Kbps，编码器选硬件（NVENC / AMD）。
2. 「视频」：基础与输出分辨率都设 1920×1080，FPS 30。
3. 「音频」：麦克风设备选对，桌面音频保持默认。
4. 主界面「来源」→ 添加「显示器采集」，选主屏。
5. 先录 10 秒测试，回放确认画面清晰、声音不爆。

### 7.2 分段录制流程

不建议一口气录 15 分钟，按分镜分 5 段录，出错只重录一段：

1. 片头（口播 + 架构图）
2. C 端主链路
3. 后台运营
4. 权限与安全
5. 工程与运维（终端 + GitHub + k6）

每段开头停 1 秒再操作，鼠标移动放慢，点击前先停顿。

### 7.3 剪辑

1. 剪映导入 5 段，按顺序排列。
2. 剪掉加载等待、输错重试的片段。
3. 加字幕：每个业务单号、错误码、关键指标单独一条字幕。
4. 关键帧用箭头或红框标注（剪映「贴纸」）。
5. 导出 1080p，文件名 `邻里鲜生-演示视频-最终版.mp4`。

### 7.4 常见问题

| 问题 | 处理 |
| --- | --- |
| 录不到鼠标点击效果 | OBS 设置里没有光标选项时，用剪映加点击音效 |
| 声音爆音 | 麦克风增益调到 -12dB 左右，离嘴 15cm |
| 画面模糊 | 导出码率低于 4000 会糊，保持 6000 以上 |
| staging 隧道断开 | 重新获取 Issue #20 的地址，先刷新页面再录 |
| 演示数据被改动 | 用 B 的最终数据截图兜底，不要现场重置数据库 |
