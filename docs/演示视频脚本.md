# 邻里鲜生 · 演示视频脚本（≤ 15 分钟）

> 用途：结项演示录屏。角色 D 负责录制与剪辑，A/B/C 出镜配合。
> 建议分辨率 1920×1080，正片 12 分钟，留 3 分钟余量。

## 0. 录制前准备（不计入时长）

1. 切换到项目数据库：`.\deploy\switch-db.ps1 project`
2. 启动全栈：`docker compose -f deploy/docker-compose.yml up -d --build`
3. 冒烟通过：`bash deploy/smoke-test.sh`（9 项全 PASS）
4. 确认演示数据：商品 6 有至少 1 条评价及商家回复；准备 1 个待支付订单用于超时关单演示。
5. 浏览器准备三个标签页：C 端 8081、B 端 8082、API 文档 8080/api/v1/doc/ui.html。
6. 关闭无关通知，统一浏览器缩放 100%。

## 1. 片头与项目概览（0:00–1:00）

- 画面：标题页 + 架构图（设计文档 3.2）。
- 口播：项目定位「单商家社区超市，支持到家配送与到店自提」，技术栈一句话带过。
- 字幕：团队分工 A/B/C/D。

## 2. C 端主链路（1:00–5:30）

| 时间 | 操作 | 讲解要点 |
| --- | --- | --- |
| 1:00 | 会员 13800000003 登录 | 令牌存 Redis，非 JWT；演示登录响应含权限点 |
| 1:30 | 浏览商品、搜索、查看详情 | 缓存与分页 |
| 2:10 | 加购、改数量、勾选结算 | 购物车唯一键合并 |
| 2:50 | 结算预览 → 使用优惠券 → 提交订单 | 金额以分计算，优惠试算不改变券状态 |
| 3:40 | 支付沙箱 → 回调成功 | 库存 locked → sold |
| 4:20 | 查看订单状态、确认收货 | 状态机合法流转 |
| 4:50 | 对商品 6 发表评价 | 展示评价与商家回复已存在 |

## 3. 后台运营链路（5:30–8:30）

| 时间 | 操作 | 讲解要点 |
| --- | --- | --- |
| 5:30 | 运营登录后台 | 权限点控制菜单与按钮 |
| 6:00 | 商品上架 / 改价 | 写操作与缓存失效 |

## 4. 一致性与安全演示（8:30–10:30）

- 8:30 超时关单：展示 2 分钟超时配置，订单自动关闭、库存与券回滚。
- 9:10 幂等：同一 Idempotency-Key 重复提交，只产生一个订单号。
- 9:50 竞态退款：关单后支付成功 → 自动退款，不出现「既关单又扣款」。
- 10:10 越权：会员访问他人订单返回 40401。

## 录制注意事项

- 每段操作前先停顿 1 秒再点击，便于后期剪辑。
- 避免出现真实手机号、密钥、Token 明文；必要时用测试账号。
- 压测数据必须是真实运行结果，不得使用估算值。
- 若某段失败，保留失败画面并在字幕标注「已知问题」，比剪掉更可信。
